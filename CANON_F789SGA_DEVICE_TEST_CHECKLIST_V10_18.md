# Canon F-789SGA — physical verification checklist (not yet performed)

For **each** candidate published method, record:

- Physical model identification and transparent casing; actual calculator hardware/version markings
- Source manual edition/revision, printed page and PDF viewer page; tester name and date
- After reset: angle mode, display mode, memory state and chosen calculation mode
- Every physical button/key sequence (including SHIFT/ALPHA, negative vs subtraction, and = confirmation)
- Expected and actual LCD display with photograph or signed independent observation
- Second standard-input variant and at least one meaningful error/domain/rounding edge case
- Mathematical verification through an independent method; domain restrictions and units
- A distinct reviewer and a final editorial approval with versioned evidence links

**Current status:** 0/10 pilot guides physically tested in this development environment; no pilot is approved. The v10.18 release contains educational *preliminary guides* only. Device testing is an external prerequisite, not an automated result.
